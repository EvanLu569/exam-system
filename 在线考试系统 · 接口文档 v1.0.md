# 在线考试系统 · 接口文档 v1.0

> 本文档是前后端开发的**唯一契约**。前端按此文档写页面和请求，后端按此文档实现接口。任何一方需要修改接口，必须先更新本文档并通知对方。

## 一、全局约定

### 1.1 基础信息

| 项目     | 值                                          |
| -------- | ------------------------------------------- |
| 后端地址 | `http://localhost:8080`                     |
| 接口前缀 | `/api`                                      |
| 数据格式 | JSON（`Content-Type: application/json`）    |
| 字符编码 | UTF-8                                       |
| 时间格式 | ISO 8601，如 `2026-09-22T10:00:00`          |
| 认证方式 | JWT，请求头 `Authorization: Bearer {token}` |

### 1.2 统一返回格式

**所有接口**（包括 WebSocket 之外的 HTTP 接口）都返回这个结构：

```json
{
  "code": 200,
  "message": "成功",
  "data": { }
}
```

| 字段    | 类型              | 说明                     |
| ------- | ----------------- | ------------------------ |
| code    | int               | 状态码，200 表示成功     |
| message | string            | 提示信息，失败时给用户看 |
| data    | object/array/null | 业务数据，失败时为 null  |

### 1.3 错误码表

| code | 含义               | 前端处理   |
| ---- | ------------------ | ---------- |
| 200  | 成功               | 取 data    |
| 400  | 参数错误           | 弹 message |
| 401  | 未登录/token 失效  | 跳转登录页 |
| 403  | 无权限             | 弹 message |
| 404  | 资源不存在         | 弹 message |
| 500  | 服务器错误         | 弹 message |
| 1001 | 用户名或密码错误   | 弹 message |
| 1002 | 用户名已存在       | 弹 message |
| 2001 | 考试未开始         | 弹 message |
| 2002 | 考试已结束         | 弹 message |
| 2003 | 已交卷，不能重复交 | 弹 message |

### 1.4 分页约定

**请求**：`?page=1&size=10`（page 从 1 开始）

**返回**：

```json
{
  "code": 200,
  "data": {
    "total": 100,
    "list": [ ]
  }
}
```

### 1.5 认证约定

- 登录成功后返回 `token`
- 前端存到 Pinia + localStorage
- 后续所有需要登录的接口，请求头带 `Authorization: Bearer {token}`
- token 过期返回 401，前端跳登录页

## 二、数据库表设计

### 2.1 user（用户表）

```sql
CREATE TABLE `user` (
  `id` BIGINT NOT NULL AUTO_INCREMENT,
  `username` VARCHAR(50) NOT NULL,
  `password` VARCHAR(100) NOT NULL,
  `role` VARCHAR(20) DEFAULT 'student',
  `create_time` DATETIME DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_username` (`username`)
) ENGINE=InnoDB;
```

### 2.2 question（题库表）

```sql
CREATE TABLE `question` (
  `id` BIGINT NOT NULL AUTO_INCREMENT,
  `content` TEXT NOT NULL,
  `options` JSON,
  `correct_answer` VARCHAR(200),
  `score` INT DEFAULT 5,
  `type` INT DEFAULT 1 COMMENT '1单选 2多选 3判断',
  `difficulty` INT DEFAULT 1 COMMENT '1简单 2中等 3困难',
  `knowledge_point` VARCHAR(100),
  `create_time` DATETIME DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`),
  KEY `idx_type` (`type`),
  KEY `idx_knowledge` (`knowledge_point`)
) ENGINE=InnoDB;
```

### 2.3 exam_paper（试卷表）

```sql
CREATE TABLE `exam_paper` (
  `id` BIGINT NOT NULL AUTO_INCREMENT,
  `name` VARCHAR(200) NOT NULL,
  `duration_minutes` INT NOT NULL,
  `total_score` INT DEFAULT 100,
  `start_time` DATETIME,
  `end_time` DATETIME,
  `status` INT DEFAULT 0 COMMENT '0未发布 1已发布 2已结束',
  `create_time` DATETIME DEFAULT CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`)
) ENGINE=InnoDB;
```

### 2.4 paper_question（试卷-题目关联表）

```sql
CREATE TABLE `paper_question` (
  `id` BIGINT NOT NULL AUTO_INCREMENT,
  `paper_id` BIGINT NOT NULL,
  `question_id` BIGINT NOT NULL,
  `score` INT DEFAULT 5,
  `sort_order` INT DEFAULT 0,
  PRIMARY KEY (`id`),
  KEY `idx_paper` (`paper_id`)
) ENGINE=InnoDB;
```

### 2.5 exam_record（考试记录表）

```sql
CREATE TABLE `exam_record` (
  `id` BIGINT NOT NULL AUTO_INCREMENT,
  `paper_id` BIGINT NOT NULL,
  `user_id` BIGINT NOT NULL,
  `total_score` INT DEFAULT 0,
  `start_time` DATETIME,
  `submit_time` DATETIME,
  `status` INT DEFAULT 0 COMMENT '0进行中 1已交卷',
  PRIMARY KEY (`id`),
  KEY `idx_paper_user` (`paper_id`, `user_id`)
) ENGINE=InnoDB;
```

### 2.6 answer_record（答题明细表）

```sql
CREATE TABLE `answer_record` (
  `id` BIGINT NOT NULL AUTO_INCREMENT,
  `record_id` BIGINT NOT NULL,
  `question_id` BIGINT NOT NULL,
  `user_answer` VARCHAR(500),
  `is_correct` TINYINT DEFAULT 0,
  `score` INT DEFAULT 0,
  PRIMARY KEY (`id`),
  KEY `idx_record` (`record_id`)
) ENGINE=InnoDB;
```

### 2.7 wrong_question（错题本）

```sql
CREATE TABLE `wrong_question` (
  `id` BIGINT NOT NULL AUTO_INCREMENT,
  `user_id` BIGINT NOT NULL,
  `question_id` BIGINT NOT NULL,
  `wrong_count` INT DEFAULT 1,
  `last_wrong_time` DATETIME,
  `next_review_time` DATETIME,
  `mastered` TINYINT DEFAULT 0,
  PRIMARY KEY (`id`),
  UNIQUE KEY `uk_user_question` (`user_id`, `question_id`)
) ENGINE=InnoDB;
```

### 模块 1：认证

#### 1.1 登录

```
POST /api/auth/login
```

**请求体**：

```json
{
  "username": "admin",
  "password": "123456"
}
```

**返回**：

```json
{
  "code": 200,
  "message": "登录成功",
  "data": {
    "id": 1,
    "username": "admin",
    "role": "admin",
    "token": "eyJhbGciOiJIUzI1NiIs..."
  }
}
```

**错误**：1001 用户名或密码错误

#### 1.2 注册

```
POST /api/auth/register
```

**请求体**：

```json
{
  "username": "student1",
  "password": "123456",
  "role": "student"
}
```

**返回**：`{ "code": 200, "message": "注册成功", "data": null }`

#### 1.3 获取当前用户

```
GET /api/auth/me
```

**返回**：

```json

```

## 五、前端开发建议

### 5.1 axios 封装

前端统一封装 axios，拦截器处理：

```javascript
// 请求拦截：自动带 token
axios.interceptors.request.use(config => {
  const token = localStorage.getItem('token')
  if (token) config.headers.Authorization = `Bearer ${token}`
  return config
})

// 响应拦截：统一处理 code
axios.interceptors.response.use(res => {
  const { code, message, data } = res.data
  if (code === 200) return data
  if (code === 401) { router.push('/login'); return }
  ElMessage.error(message)
  return Promise.reject(new Error(message))
})
```

## 六、后端开发建议

### 6.1 模块结构

后端采用 Maven 多模块结构，父模块统一管理依赖版本：

```
exam-backend/（父模块）
├── exam-common/      # 通用：统一返回、异常、JWT、拦截器、CORS
├── exam-model/       # 数据层：entity + mapper + MyBatis XML
├── exam-auth/        # 认证模块
├── exam-question/    # 题库模块
├── exam-paper/       # 试卷 + 智能组卷模块
├── exam-exam/        # 考试 + WebSocket + 统计模块
├── exam-wrong/       # 错题本模块
└── exam-application/ # 启动模块（main + application.yml）
```

包名统一为 `com.evan.examsystem`，各模块下的子包：

```
com.evan.examsystem
├── common/          # 统一返回、异常、常量
├── config/          # 配置类（跨域、拦截器、WebSocket）
├── controller/      # 接口层
├── service/         # 业务逻辑
│   └── impl/
├── mapper/          # MyBatis Mapper
├── entity/          # 数据库实体
├── dto/             # 请求参数对象
├── vo/              # 返回给前端的对象
├── task/            # 定时任务（考试倒计时）
└── util/            # 工具类（JWT）
```

### 6.2 开发顺序

```
1. 建表（执行上面的 SQL）
2. common 包：Result、ResultCode、GlobalExceptionHandler
3. 认证模块：User 实体、UserMapper、JwtUtil、AuthController
4. 题库模块：Question 实体、Mapper、Service、Controller
5. 试卷模块：Paper、PaperQuestion、Service、Controller
6. 考试模块：ExamRecord、AnswerRecord、Service、Controller
7. 判卷逻辑 + 错题本
8. 统计接口
9. WebSocket 倒计时
```

### 6.3 统一返回类示例

```java
@Data
public class Result<T> {
    private int code;
    private String message;
    private T data;

    public static <T> Result<T> success(T data) {
        Result<T> r = new Result<>();
        r.code = 200;
        r.message = "成功";
        r.data = data;
        return r;
    }

    public static <T> Result<T> error(int code, String message) {
        Result<T> r = new Result<>();
        r.code = code;
        r.message = message;
        return r;
    }
}
```
